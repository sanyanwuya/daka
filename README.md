# 每日打卡

一个极简的打卡小工具，用来记录每天做了几次，并显示连续打卡天数。

## 功能

- 点击「打卡 +1」记录今天的次数
- 刷新、关掉浏览器再打开，数据都还在
- 显示最近 7 天的记录
- 显示当前连续打卡天数（今天没打卡时从昨天开始计算）
- 「撤销今天」可以删掉今天的记录

## 怎么运行

不需要安装任何东西，数据保存在浏览器的 localStorage 里。

```bash
cd daka
python3 -m http.server 8000
```

然后浏览器打开 <http://localhost:8000>

> 直接双击 `index.html` 也能打开，但用本地服务器更接近真实环境，
> 而且浏览器的本地存储行为更标准。

## 代码结构

整个项目只有一个文件 `index.html`，里面分成三部分：

| 部分 | 作用 |
|---|---|
| `<style>` | 外观：颜色、间距、圆角 |
| `<body>` | 结构：标题、大数字、按钮、列表 |
| `<script>` | 行为：读数据、算连续天数、把数据画到界面上 |

## 数据长什么样

在浏览器本地存储里，键名是 `daka`，值是这样一段 JSON：

```json
{
  "2026-11-20": 2,
  "2026-11-21": 1
}
```

也就是「日期 → 那天打卡了几次」。
